# Code of Conduct

Be kind, be patient, assume good intent. Harassment, insults and personal
attacks are not welcome in issues, pull requests or discussions.

Maintainers may edit or remove comments and block people who don't follow
this. Report problems privately to the maintainer listed in `package.json`.

This is a short version of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
